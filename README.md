# CityWeather

Небольшой скрипт для получения данных о погоде в города через API ```wttr.in``` на Python

## Требования

- Python 3.8 или выше
- Интернет подключение

## Установка

1. Склонируйте репозиторий:

```bash
git clone https://github.com/Alexandrina-Kuzeleva/CityWeather.git
cd CityWeather
```

2. Добавьте свой файл ```Cities.txt``` или изменить файл-пример из склонированого репозитория

3. Запустите в терминале:
```bash
python main.py
```
